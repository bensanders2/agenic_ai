# AI Engineering Learning Path & Portfolio

A structured self-study path toward AI engineering roles, built on a foundation of Python automation, SQL/BI analytics, Linux administration, and hands-on LLM experience. This repo documents the journey — courses, projects, and skills — in public.

---

## Background

- **Python**: workflow automation scripting
- **SQL & BI**: IT change management, DAX, cross-platform query translation
- **Linux**: home server administration
- **LLMs**: daily hands-on use (Claude, ChatGPT, Ollama/llama3 locally) for troubleshooting, code explanation, platform migration, and technical problem-solving
- **Local AI**: running models via Ollama on home hardware

The goal: transition from BI Analyst into AI/ML engineering roles by building verifiable, practical skills with real project output.

## Notes & Approach

- Each project is built to solve something real or useful, not just as a tutorial exercise
- Where possible, projects are designed to run locally (Ollama) to demonstrate understanding of the full stack
- The IBM cert runs as a background track — steady progress rather than a sprint
- This path is designed for someone moving from BI/analytics into AI engineering, not from a software engineering background
